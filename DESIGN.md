# Hammy Run interface

Subject: a wallet-connected hamster runner for mobile and desktop. The first screen's job is to start a run.

Palette: meadow #4d7549, ink #24352b, sky #e5f0ee, canvas #f7faf5, seed #e3b852, lilac #eeebf7.
Type: Outfit for rounded display, DM Sans for body, tabular numbers for scores. All critical fonts are self-hosted.
Layout: restrained side navigation on desktop, top bar and bottom navigation on mobile. The playable garden panorama is the large centerpiece, with a narrow score and rewards column.
Signature: layered, code-drawn garden with a chunky expressive hamster, floating seeds, a picket fence, pots and distant hills. It is the actual game renderer, so the preview and play share one world.

Critique: a conventional crypto dashboard would bury the game beneath market metrics. Keep the garden dominant and use only real personal scores and a clearly explained rewards status. No fabricated yields or leaderboard players.

Site title uses ordinary text. The canvas hamster is a gameplay sprite, not a logo or visual identity asset.
